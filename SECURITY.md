# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

Security is a high priority for **AndroMac**. If you discover a security vulnerability or security bug, please report it privately.

### How to Report:
- Please **do not** report vulnerabilities through public GitHub issues.
- You can privately contact the maintainer via email or via GitHub Private Vulnerability Reporting on the repository.
- Please provide:
  1. A description of the vulnerability.
  2. Steps to reproduce or proof of concept.
  3. Potential impact and recommendations for mitigation if known.

We will acknowledge receipt within 48 hours and work on a fix as quickly as possible.
